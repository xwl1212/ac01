## Week 1 · GPIO + 串口中断

[→ 查看 week1_gpio_uart](./week1_gpio_uart/README.md)

- 芯片：STM32F103C8T6，72MHz
- 按键外部中断（EXTI0）+ 串口接收中断，双入口
- 中断只置标志，业务全部在主循环处理
- 非阻塞定时（`HAL_GetTick` 时间戳比较，不用 `HAL_Delay` 死等）
- 串口 115200 回显

## 开发环境

- STM32CubeMX 6.14.1，F1 固件包 V1.8.6
- Keil MDK 5.36（ARMCC V5.06 update 7）
- 野火小智 STM32F103C8T6 + CMSIS-DAP 下载器
- 串口助手：115200 / 8N1
